# CarePulse GUI — Hospital Management System

A comprehensive Hospital Management System developed in *C* .

---

## 🚀 Features
* *Patient Tracking & Records:* Manage inpatient/outpatient data, case history, and medical logs.
* *Financial & Billing Module:* Automated calculation of hospital stays, service fees, and senior citizen discount logic.
* *Casualty & Emergency Reporting:* Quick-entry module for emergency admissions and trauma logging.
* *Authentication & Security:* Secure login system (security.h / security.c) controlling role-based access.
* *Modular Architecture:* Multi-member design separating core logic, menus, validation, and data structures.

## ⚙️ How to Compile & Run
1. Open *Dev-C++* or your preferred C IDE.
2. Open the project folder and load *main.c* along with the module header files (member1.h, menus.h, security.h, validation.h, structs.h).
3. Compile and run the project executable to launch the GUI navigation interface.
